# 🐍 Python Basics - Mini Projects

This repository contains two simple Python programs designed to strengthen your understanding of basic programming concepts like input/output, arithmetic operations, and string handling.

---

## 🧮 Task 1: Basic Mathematical Operations

### 📌 Description
A Python script that:
- Accepts two numbers from the user
- Performs:
  - ➕ Addition
  - ➖ Subtraction
  - ✖️ Multiplication
  - ➗ Division
- Displays the result of each operation in a readable format

### 🚀 Getting Started

#### ✅ Prerequisites
Ensure Python is installed on your machine.  
Download it here 👉 [https://www.python.org/downloads/](https://www.python.org/downloads/)

#### 💻 How to Run

1. Save the script as `task_1.py`
2. Open your terminal or command prompt
3. Navigate to the folder where the assignments is saved
4. Run the script using:

```bash
python task_1.py
```
